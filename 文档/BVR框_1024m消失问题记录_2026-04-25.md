# BVR框约1024m消失问题记录（2026-04-25）

## 1. 问题现象

- 现象：BVR框在目标距离约 `1000~1024m` 时消失。
- 配置背景：`MinRangeBVR=35`、`RadarMaxTargetRange=4000`，理论上不应在 1km 附近消失。
- 额外现象：雷达扫描/锁定可继续工作，但可视化框体丢失。

## 2. 排查结论

### 2.1 已排除项

- 已排除“纯雷达侧1000/1024硬限制”：
  - 服务端实体同步路径未发现 1000/1024 距离截断。
  - BVR过滤中距离上限已对齐 `radarMaxTargetRange`。
- 已排除 `MinRangeBVR` 为主因：
  - 该参数语义为“最小交战/显示距离门限”，不是远距上限。

### 2.2 根因判定

- 根因是 **BVR框采用3D世界 billboard 绘制**，会受 Minecraft 客户端远裁剪面影响。
- 在常见视距（如 32 区块）下，世界空间对象在约 1km 量级开始被裁剪，因此出现“框在约1024m消失”。

## 3. 已实施修复（当前版本）

### 3.1 BVR混合绘制（3D + 2D HUD）

- 近距（`<=900m`）：使用 3D world billboard，保持空间感。
- 远距（`>=1100m`）：切换为 2D HUD 投影绘制，规避远裁剪面丢框。
- 过渡区（`900~1100m`）：按距离做 alpha 混合，减少模式切换抖动。

### 3.2 投影实现

- 2D HUD模式使用矩阵投影（`GLU.gluProject`）把世界相对坐标投到屏幕坐标。
- 保留原有框体纹理、状态字（`LOCK/SELECT`）、数据链双环与文本逻辑，3D/2D共用绘制核心。

## 4. 追踪器过期参数调整

- 为降低短暂丢包导致的目标瞬时消失，已将客户端追踪超时放宽：
  - `EXPIRATION_MS`: `1000 -> 3000`
  - `MISSING_SEQ_THRESHOLD`: `20 -> 60`

说明：仅放大 `EXPIRATION_MS` 不足以完全避免过早清理，因为序号阈值同样会触发删除。

## 5. 影响与风险

- 预期收益：
  - 1km外BVR框稳定性明显提升。
  - 近距保持原有3D空间感。
- 可能风险：
  - 2D HUD在屏幕边缘可能出现轻微视觉“贴边”感（已做可见范围判断）。
  - 追踪器阈值增大后，极端情况下陈旧目标保留时间略增加（通常可接受）。

## 6. 后续待定项（暂不实施）

- 是否参数化为配置文件（可选）：
  - `HUD_BLEND_START_RANGE`
  - `HUD_BLEND_END_RANGE`
  - `EXPIRATION_MS`
  - `MISSING_SEQ_THRESHOLD`
- 建议后续在实机联机环境观察一段时间，再决定是否配置化。
