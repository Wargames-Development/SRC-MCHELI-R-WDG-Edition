# 弹道导弹与中段横向机动参数化方案（调研与落地设计）

## 1. 需求摘要

- 在现有 GPS 导弹（`IsGPSMissile=true`）基础上，增加子功能 `BallisticMissile=true`：
  - 导弹不走近似平直制导，而是从发射点到着弹点走高抛弹道。
  - 需要可调“抛物线弧度”参数。
- 额外增加一类突防机动参数：
  - 导弹在飞行中段叠加横向正弦机动（蛇形机动）。
  - 最终落点保持不变。
  - 命中前一定距离（如几十米圆柱半径）自动停止横向机动，保证末段命中率。

## 2. 可行性结论

- 结论：可行，且与当前代码架构匹配度高。
- 原因：
  - 现有 AS 导弹已具备“按坐标点制导”的主链路，只需把“制导目标点”从终点改为“沿设计轨迹的动态引导点”。
  - 现有导弹每 tick 都在更新 `guidanceToPos(...)`，适合叠加轨迹塑形（抛物线 + 横向偏移）。
  - 不需要改网络协议，不需要改 GPS 点存储机制，属于弹体运动学层面的增量改造。

## 3. 建议新增参数（WeaponInfo）

- `BallisticMissile = false`
  - 是否启用弹道导弹子模式（仅建议在 `IsGPSMissile=true` 时生效）。
- `BallisticArcFactor = 0.20`
  - 抛物线弧度系数，建议范围 `0.02 ~ 1.50`。
  - 含义：弧顶附加高度与水平距离成比例。
- `BallisticArcMinHeight = 20.0`
  - 最小弧顶高度，避免近距离看不出高抛。
- `BallisticArcMaxHeight = 400.0`
  - 最大弧顶高度，防止超远程时抬升过高导致不稳定。
- `BallisticMinDistance = 80.0`
  - 小于该距离时退回普通直线制导，避免近距过度抬头。

- `BallisticLateralSine = false`
  - 是否启用中段横向正弦机动（建议仅在 `BallisticMissile=true` 时允许）。
- `BallisticLateralAmplitude = 12.0`
  - 横向机动振幅（方块）。
- `BallisticLateralWaves = 1.5`
  - 全程累计正弦波周期数（0.25~8 建议）。
- `BallisticLateralPhaseDeg = 0.0`
  - 初相位（度），用于同型弹分散轨迹。
- `BallisticLateralStartRatio = 0.20`
  - 横向机动开始进度（0~1）。
- `BallisticLateralEndRatio = 0.85`
  - 横向机动结束进度（0~1，须大于 start）。
- `BallisticTerminalNoWeaveDist = 80.0`
  - 末段“禁机动”距离（方块）。距离目标小于此值后关闭横向偏移。
- `BallisticTerminalCylinderRadius = 40.0`
  - 命中前圆柱半径触发阈值（按水平距离判定），进入该圆柱后可提前关机动。

## 4. 轨迹模型设计

## 4.1 基础轨迹：高抛抛物线

- 设发射点 `S`、目标点 `T`、当前导弹位置 `M`。
- 进度定义：
  - `u = clamp( proj(S->M on S->T) / |S->T|, 0, 1 )`
- 基础路径点（不含横向机动）：
  - `Pbase = lerp(S, T, u)`
  - `Pbase.y += 4*u*(1-u)*H`
- 其中弧高：
  - `H = clamp(max(BallisticArcMinHeight, horizontalDist(S,T) * BallisticArcFactor), 0, BallisticArcMaxHeight)`

说明：
- `4*u*(1-u)` 在 `u=0.5` 达峰值 1，天然形成“起飞抬升-中段高点-末段下压”。

## 4.2 中段横向正弦机动

- 先定义航线横向单位向量 `N`（在水平面）：
  - `D = normalize(T - S)`
  - `N = normalize(cross(up(0,1,0), D))`
  - 若 `D` 近似竖直导致退化，取 `N=(1,0,0)` 兜底。
- 仅在“中段窗口”内叠加横向偏移：
  - `u in [BallisticLateralStartRatio, BallisticLateralEndRatio]`
  - 且 `distanceToTarget > BallisticTerminalNoWeaveDist`
  - 且 `horizontalDistanceToTarget > BallisticTerminalCylinderRadius`（可选并行条件）
- 横向偏移：
  - `waveArg = 2*pi*BallisticLateralWaves*u + phase`
  - `offset = BallisticLateralAmplitude * sin(waveArg) * envelope(u)`
  - `P = Pbase + N * offset`
- `envelope(u)` 建议使用平滑窗函数（如 smoothstep）避免突兀切入切出。

## 4.3 末段保精度策略

- 满足任一条件时立即禁用横向机动，仅沿 `Pbase` 或直接 `T` 制导：
  - `distanceToTarget <= BallisticTerminalNoWeaveDist`
  - `horizontalDistanceToTarget <= BallisticTerminalCylinderRadius`
  - `u >= BallisticLateralEndRatio`
- 这样可以兼顾“中段突防”和“末段命中率”。

## 5. 与现有系统的兼容规则

- 默认不改现有行为：
  - `BallisticMissile=false` 时完全保持当前逻辑。
- 功能生效建议条件：
  - `IsGPSMissile=true`
  - `LockEntity=false`（若锁实体，目标在运动，横向机动末段会更复杂，建议先不启用）。
- 与现有机动参数协同：
  - `TurningFactor`、`MaxDegreeOfMissile` 不足会导致轨迹跟不上，应在武器配置中提高。

## 8. 风险与边界

- 超远程场景：
  - 弧高过大可能导致导弹过早升空、飞行时间过长，需依赖 `BallisticArcMaxHeight` 限制。
- 近距离场景：
  - 建议启用 `BallisticMinDistance` 退化到直线制导。
- 强机动参数冲突：
  - 若横向振幅/波数过高而 `TurningFactor` 偏低，可能出现末段纠偏不足。
- 地形遮挡：
  - 高抛能减轻地形遮挡，但不保证避障；若需要“地形跟随”需另做路径规划（不在本次范围）。

## 9. 最终结论

- 你提出的两个点都能实现：
  - `BallisticMissile` 高抛弹道（含弧度参数）。
  - 中段横向正弦机动 + 末段自动关机动保落点。
- 推荐先按“GPS 坐标导弹（`IsGPSMissile=true` 且 `LockEntity=false`）”落地第一版，风险最低、收益最高。
