# 近炸系统与子母弹系统调研方案

## 1. 现有代码实现概览

### 1.1 近炸系统（Proximity Fuse + Airburst）

- 主要配置入口：`mcheli.weapon.MCH_WeaponInfo`
  - 近炸相关：`proximityFuseDist`、`proximityFuseTick`、`proximityFuseDamage`、`proximityFuseHeight`
  - 空爆相关：`canAirburst`、`explosionAirburst`
- 主要运行逻辑：`mcheli.weapon.MCH_EntityBaseBullet`
  - 每 Tick 调用顺序（命中/空爆/近炸）：`onUpdateCollided()` -> `onUpdateAirburst()` -> `onUpdateProximityFuse()`
  - `onUpdateAirburst()`：按设定距离触发可编程空爆
  - `onUpdateProximityFuse()`：按目标接近距离触发近炸

实现特征：

1. **可编程空爆（Airburst）**：更像“距离引信”，飞到设定距离后在空中爆炸。
2. **近炸引信（Proximity Fuse）**：更像“目标接近引信”，当弹道预测距离目标足够近时触发爆炸。
3. 两者可并存，优先由每帧检查决定先触发哪一个。

---

### 1.2 普通子母弹系统（一次性分裂）

- 主要配置入口：`mcheli.weapon.MCH_WeaponInfo`
  - `bomblet`：分裂子弹数
  - `bombletSTime`：分裂倒计时
  - `bombletDiff`：分裂散布
  - `ModelBomblet`：分裂后子弹模型/子弹类型来源
- 主要运行逻辑：`mcheli.weapon.MCH_EntityBaseBullet#onUpdateBomblet()`
  - `sprinkleTime` 递减至 0 后一次性循环 `sprinkleBomblet()`
  - 分裂完成后母弹 `setDead()`

实现特征：

1. **一次性触发**：只在到点时分裂一次。
2. **瞬时释放**：一次生成 `bomblet` 枚子弹。
3. **母弹终止**：分裂后母弹立刻销毁。

---

### 1.3 空中持续布撒子母弹系统（持续生成）

- 主要配置入口：`mcheli.weapon.MCH_WeaponInfo`
  - `SpawnBulletInAir`
  - `SpawnBulletMaxNum`
  - `SpawnBulletIntervalTick`
  - `SpawnBulletPerNum`
  - `SpawnBulletInheritSpeed`
  - `DestructAfterSpawnBullet`
  - `ModelBomblet`
  - `BombletDiff`
- 主要运行逻辑：`mcheli.weapon.MCH_EntityBaseBullet#onUpdateSpreader()`
  - 运行条件：`spawnBulletInAir == true`
  - 周期触发：每到 `SpawnBulletIntervalTick` 且未超 `SpawnBulletMaxNum`
  - 每次生成：`SpawnBulletPerNum` 枚
  - 结束策略：若 `DestructAfterSpawnBullet == true` 且已达最大次数，则母弹销毁

实现特征：

1. **持续触发**：按 Tick 间隔周期生成子弹。
2. **节拍释放**：每个周期释放固定数量子弹。
3. **可选继承速度**：子弹可继承母弹运动矢量与加速度。
4. **可选自毁**：释放完成后可让母弹自毁，也可继续存在。

---

## 2. 你给出的参数组分析（空中持续布撒器）

参数：

```ini
DestructAfterSpawnBullet=true
SpawnBulletInAir = true
ModelBomblet = BOMBER_B1B_GPSBOMB_BULLET
BombletDiff = 0.0
SpawnBulletMaxNum = 1
SpawnBulletIntervalTick = 80
SpawnBulletPerNum=1
SpawnBulletInheritSpeed = true
```

逐项含义：

1. `SpawnBulletInAir = true`  
   启用“空中持续布撒”逻辑（进入 `onUpdateSpreader()` 路径）。
2. `SpawnBulletMaxNum = 1`  
   最多触发 1 次布撒周期。
3. `SpawnBulletIntervalTick = 80`  
   在母弹飞行中，每 80 Tick 检查并触发一次（本组因 max=1，实际只触发首个周期）。
4. `SpawnBulletPerNum = 1`  
   每次仅生成 1 枚子弹。
5. `ModelBomblet = BOMBER_B1B_GPSBOMB_BULLET`  
   生成的子弹类型取该武器/弹药配置。
6. `SpawnBulletInheritSpeed = true`  
   子弹继承母弹当前速度与加速度方向，轨迹更连续。
7. `BombletDiff = 0.0`  
   不加随机散布，子弹按继承轨迹飞行，几乎无扩散。
8. `DestructAfterSpawnBullet = true`  
   达到最大布撒次数后母弹自毁。

结论：  
这组参数虽然走的是“持续布撒系统”，但行为效果接近“延时释放一枚继承轨迹的子弹并自毁母弹”。它不是典型大面积子母弹散布配置，而是更偏“延时单次再投放”。

## 3. 空中持续布撒子母弹 vs 普通子母弹（核心差异）

1. **触发模型**
   - 普通子母弹：倒计时到点一次性触发。
   - 空中持续布撒：按间隔 Tick 周期触发。

2. **释放节奏**
   - 普通子母弹：瞬时释放 `bomblet` 枚。
   - 空中持续布撒：每周期释放 `SpawnBulletPerNum`，累计到 `SpawnBulletMaxNum` 次。

3. **母弹生命周期**
   - 普通子母弹：分裂后必定销毁。
   - 空中持续布撒：是否销毁由 `DestructAfterSpawnBullet` 控制。

4. **子弹速度继承**
   - 普通子母弹：通常按 `sprinkleBomblet()` 内部设定分散生成。
   - 空中持续布撒：可通过 `SpawnBulletInheritSpeed` 明确继承母弹运动。

5. **应用场景**
   - 普通子母弹：区域覆盖、一次性杀伤。
   - 空中持续布撒：航线播撒、延时连续打击、轨迹跟随投放。

## 4. 功能实现方案建议

### 4.1 近炸系统

- 保持现有近炸链路（风险最低），只调参数：
  - 对空导弹：较小 `proximityFuseDist` + 稍晚 `proximityFuseTick`
  - 防空炮弹：中等 `proximityFuseDist` + `canAirburst=true`
- 若要增强：将近炸目标筛选从“以飞机为主”扩展为“飞机+直升机+地面载具+导弹”。

### 4.2 子母弹系统

- 普通子母弹用于“爆点覆盖”：
  - `bomblet` 取较高，`bombletDiff` 取中高
- 空中持续布撒用于“路径投放”：
  - `SpawnBulletIntervalTick` 控制间隔
  - `SpawnBulletPerNum` 控制密度
  - `SpawnBulletMaxNum` 控制总持续长度

### 4.3 你这组参数的可调方向

当前参数偏“单次延迟释放”。如果目标是更明显的“持续布撒”，建议至少做其一：

1. 把 `SpawnBulletMaxNum` 提高到 3~8；
2. 把 `SpawnBulletPerNum` 提高到 2~4；
3. 把 `BombletDiff` 从 `0.0` 提到 `0.05~0.25` 形成可见散布。

## 5. AHEAD 机制可行性调研

### 5.1 机制定义与目标

AHEAD 是“近炸触发后不自爆，转为持续布撒子弹”的复合机制。  
它继承两条现有能力链路：

1. 近炸引信判定：`onUpdateProximityFuse()`
2. 持续布撒子弹：`onUpdateSpreader()`

结论：  
在当前架构中可行，且属于中低风险改造，不需要重写武器系统。

### 5.2 参数规则（按你的约束）

```ini
AHEAD=true
```

规则如下：

1. `AHEAD` 默认值 `false`。
2. `AHEAD=true` 与 `SpawnBulletInAir=true` 不能共存。
3. 若两者同时为 `true`，强制关闭 `AHEAD`（`AHEAD=false`）。
4. 在 `AHEAD=true` 且 `SpawnBulletInAir=false` 时，除 `ModelBomblet` 外，其余默认值为：

```ini
ProximityFuseDist = 15
ProximityFuseTick = 5
ProximityFuseHeight = 30
DestructAfterSpawnBullet = true
BombletDiff = 1.0
SpawnBulletMaxNum = 1
SpawnBulletIntervalTick = 1
SpawnBulletPerNum = 10
SpawnBulletInheritSpeed = true
ModelBomblet = ""
```

### 5.3 与现有行为的关键差异

现有近炸命中后流程是“爆炸 + 可选伤害 + 母弹销毁”。  
AHEAD 需要改为：

1. 近炸命中时不执行爆炸；
2. 切换到 AHEAD 触发布撒状态；
3. 用 `SpawnBullet*` 参数执行布撒；
4. 按 `DestructAfterSpawnBullet` 决定母弹是否消失。

### 5.4 边界与风险点

1. 目标筛选当前以飞行器为主，AHEAD 若需对地载具生效，需扩展筛选条件。
2. `ModelBomblet` 为空时应直接不触发布撒，避免空指针/无效生成。
3. `SpawnBulletIntervalTick` 和 `SpawnBulletPerNum` 过高时可能造成瞬时实体数量峰值。

### 5.5 A 方案更新（预解算引爆点版本）

本节采用你最新确认的方向：  
**AHEAD 不再以“靠近目标再触发”为主，而是基于火控锁定数据预解算“预计撞击点距离”，在到达 `预计撞击距离 - ProximityFuseDist` 时触发布撒。**

#### 5.5.1 激活前提（新增硬约束）

1. 必须先建立火控锁定（CAP 键预瞄圈锁定）。
2. 未建立火控锁定时，`AHEAD=true` 不生效，按常规弹药处理。
3. `AHEAD=true` 与 `SpawnBulletInAir=true` 仍不能共存；若同时为 `true`，强制 `AHEAD=false`。

#### 5.5.2 参数语义调整（采用新定义）

```ini
AHEAD=true
AheadSolveIntervalTick=2
ProximityFuseDist=15
ProximityFuseTick=5
ProximityFuseHeight=30
ModelBomblet=武器文件名称
DestructAfterSpawnBullet=true
BombletDiff=1.0
SpawnBulletMaxNum=1
SpawnBulletIntervalTick=1
SpawnBulletPerNum=10
SpawnBulletInheritSpeed=true
```

语义说明：

1. `AheadSolveIntervalTick`  
   锁定阶段解算刷新频率，默认 `2 tick`。  
   仅在“已建立火控锁定”阶段生效。
2. `ProximityFuseDist`  
   由“近炸触发距离”改为“预计撞击点提前量”。  
   触发距离 = `预计撞击点距离 - ProximityFuseDist`。
3. `ProximityFuseTick`  
   仍保留为最早激活时间门限（发射后至少 N tick 才允许触发）。
4. `ProximityFuseHeight`  
   仍保留为高度门限（低于门限不触发）。
5. `ModelBomblet` 与 `SpawnBullet*`  
   触发后布撒行为仍复用现有空中布撒机制。

#### 5.5.3 运行流程（AHEAD 预解算）

1. 火控锁定建立后，按 `AheadSolveIntervalTick=2` 刷新一次预计撞击点距离。
2. 开火时将最新解算值写入本发弹药。
3. 飞行中按距离判断：到达 `预计撞击点距离 - ProximityFuseDist` 时触发布撒。
4. 触发后按 `SpawnBullet*` 执行布撒，按 `DestructAfterSpawnBullet` 决定母弹是否消失。

#### 5.5.4 设计收益

1. 相比“贴近目标再触发”，更接近现实 AHEAD 的预装定引爆思路。
2. 解算只在锁定阶段按频率刷新，性能开销可控。
3. 允许一定误差，符合“存算点难完全精确”的实战预期。

## 6. 开发准备清单（AHEAD）

### 6.1 预计改动文件

1. `src/main/java/mcheli/weapon/MCH_WeaponInfo.java`
   - 新增参数：`ahead`
   - 新增配置解析：`AHEAD`
   - 在 `checkData()` 增加互斥与默认值注入
2. `src/main/java/mcheli/weapon/MCH_EntityBaseBullet.java`
   - 新增运行时状态：AHEAD 是否已触发
   - 调整近炸分支：AHEAD 触发后改走布撒逻辑，不自爆
   - 布撒逻辑中接入 AHEAD 状态控制

### 6.2 推荐实现顺序

1. 先做 `MCH_WeaponInfo` 参数、解析、默认值、互斥规则。
2. 再做 `MCH_EntityBaseBullet` 的 AHEAD 状态机与近炸转布撒逻辑。
3. 最后做基础验证：`compileJava`、`build -x devModJar`。

### 6.3 验收标准

1. `AHEAD=true` 时，弹体接近目标后不爆炸，改为触发布撒。
2. `AHEAD=true && SpawnBulletInAir=true` 时，AHEAD 自动失效。
3. `AHEAD=true && SpawnBulletInAir=false` 时，默认参数按本节规则生效。
4. `ModelBomblet` 合法时能生成子弹，非法或空值时安全退出不崩溃。
